# VOC Improve 상시 개발 원칙

## 완료 기준

- 사용자 기능과 품질 운영 기능은 웹브라우저에서 실행할 수 있어야 한다.
- CLI 기능에는 대응 웹 UI·API·진행·오류·결과 화면을 제공한다.
- 기능 변경 후 웹 HTTP, 입력 검증, JavaScript 구문과 관련 자동 테스트를 검증한다.
- 공식 품질 실행은 TXT·XML·HTML·JUnit 증적과 실행 이력을 남긴다.
- 결과 점수에는 실행일을 함께 표시하고, 패키지 생성일과 평가 실행일을 구분한다.
- API 키·개인정보·민감 운영정보의 실제 값은 소스·웹·로그·발표자료에 기록하지 않는다.
- 작업 완료 시 개발 원장, 웹 발표자료와 배포용 발표자료를 함께 갱신한다.

## 점수 표기 원칙

- 과거 실행값은 `과거 기준선`과 실행일을 표시한다.
- 현재 배포판정은 실행 시각 기준 최신 보관 E2E·Judge 조합을 사용한다.
- 기존 증적으로 패키지만 다시 만들었으면 `재실행 없음`을 명시한다.
