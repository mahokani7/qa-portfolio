# OBS + AWS 프로그램 시연 가이드 — 2026-08-04

## 권장 시연 구성

이번 과제는 다음 두 화면을 이어서 녹화합니다.

1. **로컬 PC**: VOC 웹 프로그램 정상 실행과 실제 화면 시연
2. **AWS CloudShell**: S3에서 같은 프로그램 패키지를 내려받아 pytest 32건 실행

AWS CloudShell은 외부 인바운드 포트를 제공하지 않으므로 `web_app.py`의 8000번 화면을
인터넷에 공개하는 용도로 사용할 수 없습니다. 웹 화면 자체를 AWS 주소로 공개하려면
ECS Fargate + ALB 같은 별도 배포가 필요하며, 이번 1~11번 평가에는 필수가 아닙니다.

## 1. OBS 설정

- 장면 이름: `VOC AWS 최종 시연`
- 소스: `디스플레이 캡처` 1개, `오디오 입력 캡처` 1개
- 해상도: `1920×1080`
- FPS: `30`
- 출력 모드: `단순`
- 녹화 품질: `높은 품질, 중간 파일 크기`
- 녹화 형식: `MKV`
- 마이크: 발표용 마이크 선택
- 데스크톱 오디오: 알림음 방지를 위해 끄기

녹화가 끝난 뒤 OBS의 **파일 → 녹화 리먹싱**에서 MKV를 MP4로 변환합니다.
본 촬영 전 30초 테스트 녹화로 화면 글자와 음성을 반드시 확인합니다.

## 4. AWS CloudShell에서 프로그램 실행

AWS 콘솔 리전을 서울로 맞추고 CloudShell을 전체 화면 새 탭으로 엽니다.

```bash
export AWS_REGION=ap-northeast-2
export BUCKET=voc-qa-team3-696155685087-20260804-qa

aws sts get-caller-identity
aws s3 ls "s3://$BUCKET/" --recursive --human-readable --summarize

mkdir -p ~/voc_demo
cd ~/voc_demo
aws s3 cp "s3://$BUCKET/packages/voc_qa_program.zip" .
unzip -o -q voc_qa_program.zip

python3 --version
PYTHON_BIN=python3
if ! $PYTHON_BIN -c 'import sys; assert sys.version_info >= (3, 10)'; then
  sudo dnf install -y python3.11
  PYTHON_BIN=python3.11
fi

$PYTHON_BIN -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install grpcio protobuf "mcp>=1.2" "openai>=1.66" \
  "anthropic>=0.39" python-dotenv pytest pytest-asyncio

python -m pytest \
  quality_diagnosis/test_agent_unit.py \
  quality_diagnosis/test_pipeline_e2e.py \
  quality_diagnosis/test_fault_tolerance.py \
  quality_diagnosis/test_mcp_tools.py \
  quality_diagnosis/test_llm_judge.py \
  quality_diagnosis/test_release_defects.py \
  -v -p no:cacheprovider
```

`pip install`은 녹화 전에 미리 끝내고, 본 영상에서는 S3 다운로드부터 `32 passed`까지
보여주는 편이 좋습니다.

## 5. AWS 보안과 감사 시연

```bash
aws s3api get-public-access-block --bucket "$BUCKET"
aws s3api get-bucket-encryption --bucket "$BUCKET"
aws s3api head-object \
  --bucket "$BUCKET" \
  --key qa-evidence/pytest_report.html \
  --query '{Encryption:ServerSideEncryption,Size:ContentLength,Modified:LastModified}'

curl -s -o /dev/null -w 'HTTP %{http_code}\n' \
  "https://$BUCKET.s3.$AWS_REGION.amazonaws.com/qa-evidence/pytest_report.html"
```

촬영 포인트:

- 퍼블릭 차단 4개 값 모두 `true`
- 암호화 `AES256`
- 익명 접근 `HTTP 403`
- CloudTrail의 `CreateBucket`, `PutBucketPublicAccessBlock`, `PutBucketEncryption`
