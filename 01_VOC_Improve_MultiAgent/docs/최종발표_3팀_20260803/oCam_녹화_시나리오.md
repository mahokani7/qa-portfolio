## 1. oCam 설정

메뉴 이름은 oCam 버전에 따라 조금 다를 수 있습니다. 값만 맞추면 됩니다.

| 항목 | 설정값 | 이유 |
| --- | --- | --- |
| 녹화 영역 | **전체 화면 (1920×1080)** | 슬라이드와 터미널을 오가므로 영역 고정이 유리 |
| 화면 해상도 | 1920×1080 고정 | 다른 해상도면 터미널 글자가 뭉개짐 |
| FPS | **30** | 화면 녹화에 충분, 파일 크기도 적정 |
| 비디오 코덱 | **H.264 (MP4)** | 제출·재생 호환성이 가장 좋음 |
| 오디오 | **마이크 ON + 시스템 소리 OFF** | 알림음 유입 차단 |
| 마우스 커서 | **포함 + 클릭 효과 ON** | 어느 버튼을 눌렀는지 보여야 함 |
| 저장 경로 | `C:\qaeduc2\VOC_Improve_1\aws_upload\video\` | 산출물과 같은 위치에 모음 |
| 단축키 | 녹화 시작·정지 `F2` / 일시정지 `F3` | 마우스로 oCam 창을 찾지 않기 위함 |

**녹화 시작 전 반드시 30초짜리 테스트 녹화를 하고, 재생해서 목소리가 들리는지
확인하세요.** 10분 찍고 소리가 없는 게 가장 흔한 사고입니다.

## 2. 녹화 전 체크리스트

### 화면 정리
- [ ] 바탕화면 아이콘 정리 또는 깨끗한 배경으로 변경
- [ ] **Windows 알림 끄기** — 설정 → 시스템 → 알림 → **집중 지원(방해 금지) ON**
- [ ] 카카오톡·메일·Slack 등 팝업 앱 **완전 종료**
- [ ] 브라우저 **북마크바 숨기기**, 개인 탭 전부 닫기
- [ ] 시크릿 창 또는 새 프로필로 AWS 콘솔 로그인 (자동완성 노출 방지)
- [ ] VS Code: 확대 배율 **150%** (`Ctrl` + `+`), 터미널 글꼴 크게
- [ ] PowerPoint: **발표자 보기 대신 단일 화면**으로 (노트가 녹화되면 안 됨)

### 보안 — 영상에 절대 나오면 안 되는 것
- [ ] **`.env` 파일을 편집기에서 열지 않기** (API 키 노출)
- [ ] AWS **액세스 키 / 시크릿 키** 화면 금지 (CloudShell을 쓰면 아예 등장하지 않음)
- [ ] AWS **계정 ID 12자리** — 우측 상단 계정 메뉴를 펼치지 않기
- [ ] `aws sts get-caller-identity` 출력의 **Account 숫자는 편집에서 모자이크**
      (ARN의 `user/이름` 부분만 보이면 충분합니다)
- [ ] **root 계정 로그인 금지** — 반드시 IAM 사용자로 로그인한 상태에서 녹화
- [ ] VOC 데이터에 실제 고객 개인정보가 없는지 확인 (`voc.csv`는 학습용 샘플)

### 사전 실행 (녹화에 담지 않을 준비 작업)
- [ ] AWS Budgets에 **Zero Spend Budget** 생성 완료
- [ ] CloudShell 한 번 열어서 초기화 완료 (첫 실행은 1분 이상 걸립니다)
- [ ] CloudShell에서 `pip install` **미리 1회 실행** — 영상에서는 `pytest`부터 담기
- [ ] `python scripts/build_aws_evidence.py` 미리 1회 성공 확인
- [ ] `python scripts/pack_for_cloudshell.py` 로 ZIP 2개 생성 후 CloudShell 업로드 완료
- [ ] 발표대본 인쇄 또는 **두 번째 모니터**에 띄우기 (녹화 화면에는 절대 띄우지 않기)

## 5. 촬영 요령

**슬라이드 구간 (테이크 A·D)**
- 슬라이드 쇼를 먼저 시작하고, **F2로 녹화를 시작한 뒤 2초 쉬었다가** 말을 시작합니다.
- 숫자를 말할 때는 **마우스 커서로 해당 숫자를 짚습니다.** 커서가 곧 포인터입니다.
- 슬라이드를 넘긴 직후 **0.5초 쉬고** 다음 문장을 시작하면 편집점이 깔끔합니다.

**터미널 구간 (테이크 B)**
- 명령어를 **타이핑하지 말고 붙여넣기** 하세요. 오타 한 번이면 테이크를 다시 찍습니다.
- 실행 결과가 스크롤되면 **`32 passed` 줄이 보이는 위치에서 3초 멈춥니다.**

**AWS 구간 (테이크 C)**
- 명령은 `AWS_시연_명령어.md` 를 **메모장에 미리 열어두고 순서대로 붙여넣기**.
- 출력이 긴 명령(`get-bucket-encryption` 등)은 **결과가 다 나온 뒤 2초 정지**.
- `curl` 로 **HTTP 403**이 나오는 순간은 이번 영상의 하이라이트입니다.
  **"200이 나오면 보안 결함입니다"** 라고 말하며 3초 이상 보여주세요.
- 마지막 `list-buckets` 결과의 **빈 배열 `[]`** 도 3초 이상 보여줍니다.

**음성**
- 마이크와 입 사이 **20~30cm** 유지, 키보드 소리가 크면 마이크를 키보드에서 멀리.
- 문장 끝을 흐리지 말고 **끝까지 발음**합니다.
- 말이 막히면 그대로 멈췄다가 **그 문장만 다시** 말하세요. 편집으로 잘라냅니다.
