# AWS 발표 촬영 체크리스트 — 2026-08-04

## 현재 실습 자원

- 리전: `ap-northeast-2` (서울)
- IAM 사용자: `voc-qa-team3`
- 임시 버킷: `voc-qa-team3-696155685087-20260804-qa`
- 업로드 결과: QA 증적 8개 + ZIP 2개 = 총 10개
- 퍼블릭 접근 차단: 4개 항목 모두 `true`
- 기본 암호화: `SSE-S3 (AES256)`
- 익명 URL 확인: `HTTP 403`

> 녹화 영상에서는 AWS 계정 ID와 사용자 ID를 가리거나 흐리게 처리합니다.

## CloudShell 촬영 명령

AWS 콘솔 상단에서 CloudShell을 열고 다음을 순서대로 실행합니다.

```bash
export AWS_REGION=ap-northeast-2
export BUCKET=voc-qa-team3-696155685087-20260804-qa

aws sts get-caller-identity

aws s3 ls "s3://$BUCKET/" --recursive --human-readable --summarize

aws s3api get-public-access-block --bucket "$BUCKET"

aws s3api get-bucket-encryption --bucket "$BUCKET"

aws s3api head-object \
  --bucket "$BUCKET" \
  --key qa-evidence/pytest_report.html \
  --query '{Encryption:ServerSideEncryption,Size:ContentLength,Modified:LastModified}'
```

확인해야 할 화면:

1. 객체가 총 10개 조회됨
2. `BlockPublicAcls`, `IgnorePublicAcls`, `BlockPublicPolicy`, `RestrictPublicBuckets`가 모두 `true`
3. 버킷과 객체의 암호화가 `AES256`

## CloudTrail 촬영 순서

1. AWS 콘솔에서 **CloudTrail → 이벤트 기록**으로 이동
2. 이벤트 이름 필터로 `CreateBucket` 검색
3. 사용자 이름 `voc-qa-team3`, 버킷 이름, 이벤트 시각 확인
4. 같은 방식으로 `PutBucketPublicAccessBlock` 검색
5. 같은 방식으로 `PutBucketEncryption` 검색
6. 삭제 후에는 `DeleteBucket`까지 검색하여 최종 화면 추가

CloudTrail 이벤트는 수 분 늦게 나타날 수 있습니다. S3 파일 업로드 `PutObject`는 데이터 이벤트이므로 기본 이벤트 기록에는 나타나지 않을 수 있습니다.

## 촬영 후 삭제 요청

CloudShell과 삭제 전 CloudTrail 화면을 촬영한 다음 대화창에 다음과 같이 입력합니다.

```text
CloudShell/CloudTrail 촬영 완료, 삭제해줘
```

그 후 객체 10개와 임시 버킷을 삭제하고 `DeleteBucket` 이벤트를 확인합니다.
