## API 연결 오류와 보완

확인 결과:

- OpenAI API 키 설정 여부: True
- Anthropic API 키 설정 여부: True
- Agent: 6/6 정상
- `api.openai.com:443` TCP 연결 실패
- `api.anthropic.com:443` TCP 연결 실패

따라서 오류 원인은 키 누락이 아니라 외부 443 네트워크/방화벽 차단이다.

보완 내용:

- `/analyze`에서 `Connection error`를 감지하면 동일한 6-Agent 계약의 결정론적 오프라인 분석으로 자동 전환한다.
- 응답에 다음 정보를 포함한다.
  - `execution_mode: offline_fallback`
  - `fallback_reason: PROVIDER_NETWORK_UNAVAILABLE`
  - 생성된 결과 보고서명
- 웹 결과에 `OFFLINE FALLBACK` 안내를 표시한다.
- 실제 테스트에서 HTTP 200, 1/1 PASS 결과를 확인했다.
- 외부 443이 허용되면 Live API를 우선 사용하고, 막혀 있으면 시연이 중단되지 않는다.
