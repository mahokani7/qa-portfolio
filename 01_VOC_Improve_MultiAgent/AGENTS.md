# VOC_Improve_1 개발 필수 지침

이 프로젝트에서 수행하는 모든 향후 개발에 아래 조건을 적용한다.

1. 작업 시작 전 `docs/개발원칙_발표및웹적용.md`와 `docs/개발진행_발표원장.md`를 확인한다.
2. 모든 사용자 기능과 품질 운영 기능은 웹브라우저에서 실행할 수 있게 구현한다.
3. CLI 또는 내부 자동화 기능을 추가하면 대응하는 웹 UI, 서버 API, 진행·오류·결과 화면을 함께 제공한다.
4. 기능 변경 후 웹 HTTP, 입력 검증, JavaScript 구문, 관련 자동 테스트를 검증한다.
5. 작업 완료 시 `docs/개발진행_발표원장.md`에 문제·구현·웹 적용·검증·발표 핵심을 추가한다.
6. `docs/발표자료_개발과정_2026-07-14_현재.md`와 `/presentation` 웹 슬라이드에 발표할 내용을 반영한다.
7. API 키, 개인정보, 민감한 운영정보의 실제 값은 소스·웹·로그·발표자료에 기록하지 않는다.
8. 웹 적용과 발표자료 갱신이 빠진 기능은 완료로 보고하지 않는다.
9. 공식 품질 테스트를 실행할 때마다 발표자료와 별도로 타임스탬프가 붙은 TXT·XML·HTML
   실행 증적을 생성하고 `quality_diagnosis/reports/test_execution_history.jsonl`에 누적한다.

protobuf 생성물, 패키지 메타데이터처럼 직접 실행 대상이 아닌 내부 변경은 독립 웹 버튼을
생략할 수 있다. 단, 그것을 사용하는 최종 기능과 검증 결과는 웹에서 확인할 수 있어야 한다.
