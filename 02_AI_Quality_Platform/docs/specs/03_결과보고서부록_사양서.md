# 03. 결과 보고서 — 부록(Appendix) 사양서 (📄 결과 보고서 탭)

> 대상 기능: 정식 보고서(DOCX/PDF/HTML) 하단의 **부록 — "대시보드 전체 스냅샷"**.
> 부록은 대시보드 화면(최종 결론 · 고도화 지표 · 운영 모니터링)을 **보고서 생성 시점 기준으로 정적 문서에 담는다.**
> 파일: `quality/formal_report_generator.py`. 공통 전제는 `00_공통_컨텍스트.md`.

## 0) 개요 / 진입점
- **보고서 생성 함수(시그니처 유지)**:
  - `generate_docx_report(pipeline_outputs, output_path, run_dir=None) -> Path`
  - `generate_pdf_report(pipeline_outputs, output_path, run_dir=None) -> Path`
  - `generate_html_report(pipeline_outputs, run_dir=None) -> str`
- **부록 컨텍스트 빌더**: `build_appendix_context(pipeline_outputs, tmp_dir, rule_context, api_context, run_dir=None) -> ctx(dict)`.
  - `run_dir` = 조회 대상 실행 폴더. 그 실행에 동결 스냅샷이 있으면 **라이브 대신 저장된 값**으로 재현.
- **포맷별 렌더러**: `_appendix_html(ctx)->str`, `_appendix_docx(doc, ctx)`, `_appendix_pdf(ctx, styles)->list`. 세 포맷은 **동일 내용/구성**을 각 포맷 문법으로 그린다.
- **대시보드 연동**: `render_report_tab(result_json_path, run_id)` — `run_dir = result_json_path.parent`를 generate_*에 전달. 탭 열기/🔄 새로고침 시 실시간 생성, DOCX/PDF 다운로드 버튼 + HTML 미리보기.
- **비용**: 부록은 **비용 0원 데이터만** 포함(검색품질·RAG on/off는 OpenAI 비용이라 제외, 안내만).

## 1) 부록 구조 (A / B / C)
부록 제목: **"부록. 대시보드 전체 스냅샷"** + "본 부록은 대시보드 화면을 보고서 생성 시점({generated_at}) 기준으로 담은 것입니다."

### A. 최종 결론
- **데이터**: `rule_context`, `api_context`의 overview/metrics에서 파생.
  - `_agent_concl(context) -> {pass, total, rate(success_rate), verdict, weak_label, weak_score}` (가장 취약한 지표 = min score).
- **표시**: 규칙 기반 / API 기반 각각 "합격률 X%(p/total) · 판정 · 가장 취약: 지표(점수)". (HTML 4열 표 / DOCX·PDF kv표)

### B. 고도화 지표 (요약)
- **데이터**(모두 비용 0원, `build_appendix_context`에서 수집): `coverage`(커버리지 갭), `redteam`(레드티밍), `pii`(PII), `cost`(비용추적), `halluc`(환각검증), `regression`(회귀). → 각각 `quality/*.py` 함수 호출.
- **표시**(항목별 1줄): 🗂️ 커버리지 갭 %/미커버, 🛡️ 레드티밍 방어율, 🔐 PII 노출 유무, 💰 비용(토큰/원), 🧪 환각 의심 건수, 🔁 회귀(baseline→current, 회귀/개선 건수).
- **주석**: "※ 검색 품질·RAG on/off는 OpenAI 호출(비용)이라 부록에서 제외 — 대시보드 실시간 탭에서 확인."
- **에러 처리**: 각 지표 수집 실패 시 `{"error": ...}`로 담고 해당 줄은 생략.

### C. 운영 모니터링 · 성능 스냅샷 ★ (부록 핵심)
- **데이터 소스 결정**: `ctx["ops"] = load_ops_snapshot(run_dir)`(있으면 동결값) **else** `build_ops_snapshot(tmp_dir)`(라이브). (`quality/ops_snapshot.py`, 사양서 02 참조)
- **동결 표시**: `summary.frozen`이면 "📸 이 섹션은 {saved_at} 시점에 저장된 스냅샷입니다(과거 값 고정)" 문구.
- **구성**:
  - **C-1. 실시간 알림 상태(Golden Signals)**: `ops["alerts"]` → 알림/상태/심각도 표. `_alert_label(state)`로 🟢/🟡/🔴 라벨.
  - **C-2. 운영 요약 지표**: `_ops_summary_rows(summary)` → (앱: 캡처시각/요청률/오류율/p95) + (k6: 총요청·VUs/반복/avg·p95·p99/오류율·checks). k6 없으면 "k6는 부하테스트 직후에만 표시" 안내.
  - **C-3~. 그래프**: `ops["grafana_panels"]`(실제 Grafana 패널 PNG, 대시보드와 동일)이 있으면 **섹션·패널별로 그대로 삽입**, 없으면 `ops["charts"]`(matplotlib golden/traffic/duration/k6)로 **폴백**.
- **Prometheus 미연결**: `summary.prometheus_available`가 False면 "⚠️ Prometheus 연결 불가 — docker/k6 실행 후 재생성" 안내(죽지 않음).

## 2) 공용 헬퍼 (부록 C, 3포맷 공통 — 시그니처 유지)
- `_ALERT_STATE_LABEL`, `_alert_label(state)->str`
- `_fmt_metric(v, unit="", digits=2)->str` (None→"데이터 없음", unit=="int"→천단위)
- `_ops_summary_rows(summary) -> (app_rows, k6_rows)` (k6는 `k6_total`이 있을 때만)
- `_OPS_CHART_ORDER` = (("golden","운영 대시보드..."),("traffic","트래픽 & 오류..."),("duration","응답시간 분포..."),("k6","k6 성능..."))

## 3) 포맷별 유의사항
- **HTML**: `_img_tag(path, max_width)`로 base64 인라인 이미지(자체 완결형). 표는 `_html_table(headers, rows)`.
- **DOCX**(python-docx): `doc.add_picture(path, width=Cm(...))`, 표는 `_add_kv_table(doc, rows)`. 한글 폰트(맑은 고딕) 설정 필요.
- **PDF**(reportlab): `_pdf_image(path, width)`(PIL로 비율 계산), 표는 `Table/TableStyle`. 한글 폰트 등록 필요.
- **이미지 크기**: Grafana 패널 stat은 작게, timeseries는 넓게. 폭 초과 스크롤(HTML)·페이지 폭 맞춤(DOCX/PDF).

## 4) 데이터 흐름 요약
```
render_report_tab(result_json_path)         # 대시보드 결과 보고서 탭
  run_dir = result_json_path.parent
  → generate_{docx,pdf,html}_report(results, out, run_dir=run_dir)
      → build_appendix_context(..., run_dir)
          A: rule/api context 요약
          B: coverage/redteam/pii/cost/halluc/regression (quality/*.py, 무료)
          C: ops = load_ops_snapshot(run_dir) or build_ops_snapshot(tmp)   # 동결 우선
      → _appendix_{html,docx,pdf}(ctx)       # 동일 구성, 포맷별 렌더
```

## 5) 수용 기준
1. 스냅샷이 있는 실행의 보고서 부록 C에 **실제 Grafana 패널 이미지**(대시보드와 동일)가 섹션별로 들어감.
2. 스냅샷이 없으면 부록 C가 **matplotlib 차트로 폴백**(보고서 안 깨짐).
3. 동결 스냅샷 사용 시 "📸 과거 값 고정" 문구 + C-2에 그 시점 k6 수치(예: 총 600, p95 수십 ms).
4. Prometheus 미연결이어도 A/B는 정상 생성되고 C만 안내 문구.
5. DOCX/PDF/HTML **세 포맷 모두** 동일 부록 구성(A/B/C, C-1~C-6)으로 생성 성공.
6. 부록은 OpenAI 호출을 하지 않는다(비용 0원). 검색품질·RAG on/off는 제외 + 안내만.
