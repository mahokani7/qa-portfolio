RAG 챗봇은 LLM이 모르는 내용을 외워서 답하는 방식이 아니라, 질문이 들어오면 내 문서에서 관련 내용을 먼저 찾아서 그 근거로 답하게 하는 구조입니다.
먼저 문서 업로드 → 텍스트 분할 → 임베딩·벡터DB 저장 → 질문 시 검색 → 근거와 함께 답변 흐름으로 작은 완성본 작성
처음에는 PDF 대신 .txt 또는 .md 문서로 시작하면 오류를 훨씬 줄일 수 있음
처음에는 **“내 문서를 읽고 답하는 사내 규정/교육자료 챗봇”**처럼 범위를 작게 잡아 만듬


1. 완성 목표

예를 들어 documents/ 폴더에 다음 자료를 넣습니다.

documents/
 ├─ 교육과정_안내.md
 ├─ 출결규정.txt
 └─ FAQ.txt

사용자가 질문합니다.

“결석은 몇 번까지 가능한가요?”

챗봇 처리 흐름은 다음과 같습니다.

사용자 질문
   ↓
질문을 숫자 벡터로 변환
   ↓
문서 조각 중 가장 관련 있는 내용 검색
   ↓
검색된 문서 내용 + 질문을 LLM에 전달
   ↓
근거 기반 답변 생성

2. 권장 실습 기술 구성

처음 실습은 아래 구성이 가장 단순합니다.

구분	사용 기술
화면	Streamlit
LLM	OpenAI API
임베딩	OpenAI Embeddings
벡터 DB	ChromaDB
문서 처리	LangChain
문서 형식	우선 .txt, .md

PDF, Word, 한글 파일은 나중에 추가하는 것이 좋습니다. 처음부터 PDF까지 넣으면 설치 오류와 문서 추출 오류가 늘어납니다.


3. 프로젝트 폴더 구조

새 폴더를 하나 만듭니다.

rag_chatbot/
│
├─ app.py
├─ ingest.py
├─ requirements.txt
├─ .env
│
├─ documents/
│   ├─ 교육과정_안내.md
│   ├─ 출결규정.txt
│   └─ FAQ.txt
│
└─ chroma_db/

chroma_db 폴더는 프로그램 실행 후 자동 생성됩니다.


python ingest.py

정상이라면 chroma_db 폴더가 생깁니다.

문서를 새로 추가하거나 수정한 뒤에는 기존 DB를 지우고 다시 만듭니다.

Remove-Item -Recurse -Force chroma_db
python ingest.py


streamlit run app.py

streamlit 명령이 인식되지 않으면 다음 명령을 사용하면 됩니다.

python -m streamlit run app.py

9. 테스트 질문

아래 질문으로 먼저 확인해 보세요.

수료하려면 출석률이 얼마나 되어야 하나요?
지각은 몇 번 하면 결석으로 처리되나요?
비전공자도 수강할 수 있나요?
교육 과정에 React 수업이 있나요?

마지막 질문처럼 문서에 없는 내용은 다음과 비슷하게 나와야 정상입니다.

제공된 문서에서는 React 수업 여부를 확인할 수 없습니다.

이 점이 일반 챗봇과 RAG 챗봇의 중요한 차이입니다. 모르는 내용을 그럴듯하게 만들지 않고, 등록한 문서 범위 안에서만 답변하도록 만드는 것입니다.


10. 전체 프로그램 흐름

[1] documents 폴더에 문서 저장
              ↓
[2] ingest.py 실행
              ↓
문서 읽기
              ↓
문서 분할(chunking)
              ↓
임베딩 생성
              ↓
ChromaDB에 저장
              ↓
[3] app.py 실행
              ↓
사용자 질문 입력
              ↓
질문과 유사한 문서 조각 검색
              ↓
검색 문서 + 질문을 LLM에 전달
              ↓
근거 기반 답변 + 출처 표시



11. 이후 확장 순서

첫 완성본이 정상 작동하면 다음 순서로 확장하는 것이 좋습니다.

PDF 문서 업로드 기능 추가
Word 문서와 한글 문서 변환 기능 추가
사용자가 화면에서 파일을 직접 업로드하도록 변경
답변에 페이지 번호와 문서명 표시
검색 결과가 낮으면 “관련 근거 부족”으로 답변
대화 이력과 이전 질문을 반영
RAG 챗봇 품질평가용 테스트 케이스 작성
정확성·근거성·환각 여부를 Judge Agent로 자동 평가

특히 꿈틀이님이 진행 중인 AI Agent 품질관리 과정과 연결하려면, 이 RAG 챗봇을 만든 뒤 **“검색은 되었는가, 근거와 답변이 일치하는가, 문서에 없는 내용을 만들어 내는가”**를 평가하는 테스트 프로젝트로 확장하면 매우 좋은 실습 주제가 됩니다.
