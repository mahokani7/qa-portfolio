# QA 문서 산출물 — AI 챗봇 QA 파이프라인

`06_AI_Chatbot_QA`와 같은 팀 프로젝트(4인)에서 나온 QA 프로세스 문서 13종입니다. 실행하는 프로그램이 아니라 **QA 프로세스 설계 및 문서화 프로젝트**이며, 코드보다 QA 프로세스 이해도를 보여주는 자료로 남겼습니다.

> 이 팀 프로젝트는 원래 초기 코드(`03_AI_Chatbot_QA_Pipeline`)와 확장판(`06_AI_Chatbot_QA`) 두 스냅샷으로 나뉘어 있었는데, 03은 06으로 완전히 대체되어 저장소에서 제외했습니다.

**왜 필요한가**: 요구사항 → WBS → 테스트 계획 → 결함 관리 → 재검증으로 이어지는 QA 프로세스를 문서로 남기지 않으면, 팀 밖에서는 무엇을 근거로 품질을 판단했는지 확인할 방법이 없습니다.
