# QA 문서 산출물 — AI 챗봇 QA 파이프라인

`03_AI_Chatbot_QA_Pipeline` / `06_AI_Chatbot_QA`와 같은 팀 프로젝트(4인)에서 나온 QA 프로세스 문서 13종입니다. 실행하는 프로그램이 아니라 문서 산출물이며, 코드보다 QA 프로세스 이해도를 보여주는 자료로 남겼습니다.

## Project Type

## My Role

이 문서 세트 중 제가 직접 작성한 것은 다음 2건입니다.

- `10_AI_챗봇_단위테스트_계획서.docx` — 단위 테스트 계획 설계
- `11_AI_챗봇_통합테스트_계획서.docx` — 통합 테스트 계획 설계
