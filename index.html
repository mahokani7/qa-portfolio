  • LLM Judge, Rule-based 평가, PII Scan, Red Team

09 FullStack Web QA 개인 프로젝트 Web QA

React + Express 애플리케이션을 대상으로 Cypress E2E, Jest 통합 테스트, Node 단위 테스트를 구성했습니다.

담당
  • 테스트 대상 Express+React 앱과 Cypress/Jest 테스트 스위트 작성
  • Cypress는 cy.intercept()로 API를 네트워크 레벨에서 스텁 처리해 DB 연결 없이 프론트엔드 로직만 독립 검증
  • 비밀번호 검증 로직은 경계값(빈 값·길이 초과·특수문자 누락 등) 위주로 단위 테스트 설계
발견한 문제 → 원인 → 조치 → 재검증
  • 발견한 문제 — npm test 실행 시 테스트 러너의 대상 파일이 중복되어 실패
  • 원인 — 단위(node:test)와 통합(Jest) 실행 범위가 겹쳐 동일 파일을 서로 다른 러너가 처리
  • 조치 — test:unit / test:integration으로 실행 범위 분리
  • 재검증 — 단위 5건 + 통합 4건, 전부 PASS(exit 0)
결과 — MongoDB 없이도 테스트는 모델을 모킹해 통과합니다. 실행: npm test
